## 1. 六星占術アプリの主要機能（要件定義）
まずは「これだけは外せない」という基本機能を定義します。
### ① 運命星の自動算出機能ユーザーが生年月日を入力すると、以下の要素を自動で導き出します。
- **運命星**： 土星人、金星人、火星人、天王星人、木星人、水星人
- **属性**： 陽（＋）か 陰（－）か霊合
- **星人の判定**： 占命盤の向かい合う星の影響を受ける特殊な条件の判定
### ② 運命周期（バイオリズム）の表示
六星占術の醍醐味である「12の運命周期」を可視化します。
- **年運・月運・日運**： 「種子」から「減退（大殺界）」までのサイクルを表示。
- **カレンダー連携**： 「この日は大殺界だから大人しくしよう」と一目でわかるカレンダー機能。
### ③ 性格・相性診断
- **基本性格**： 各運命星に基づいた性格解説。
- **相性診断**： 自分と相手の運命周期を掛け合わせた相性（「再会」の時期に会うと良いなど）の提示。
### ④ プッシュ通知
- 「**今日は達成の日です。積極的に動きましょう！**」
- 「**明日から大殺界に入ります。準備をしましょう**」
といった、行動指針となる通知。
## 2. ロジックの仕組み（開発の肝）
アプリを作る上で、バックエンド（計算部分）に組み込む必要があるステップは以下の通りです。
- **運命数（1〜60）の算出： 生年月日を特定の対照表（運命数表）に当てはめます。
- **星数の算出**： $運命数 - 1 + 誕生日の日 = 星数$。
※星数が60を超えた場合は60を引く。
- **運命星の特定**： 星数によって火星人〜水星人が決まります。
- **干支による（＋/－）判定**： 生まれ年の干支によって、その星人の「陽」か「陰」が決まります。
## 3.UI/UX コンセプト
### 1. ビジュアル・アイデンティティ
**カラーパレット**:
- **ベース**： 深夜の六本木を彷彿とさせる「ミッドナイトブラック」と、重厚な木目調の「ダークブラウン」。
- **アクセント**： 鈍く光る「アンティークゴールド」と、血のような「クリムゾンレッド」。

- **質感**： デジタルなフラットデザインではなく、古いホテルのラウンジの革椅子や、タバコの煙が揺らめくような「粒子の粗いグラデーション」。

**フォント**:
明朝体をベースにしつつ、少し掠れたような質感。縦書きを効果的に使い、言葉の「重圧」を表現します。

### 2. UX（ユーザー体験）の演出
- **「孤独」を感じさせる空間演出**：
アプリ起動時、賑やかな喧騒から一転して「しんと静まり返った豪華な書斎」に入るような演出。
BGMはピアノや、雨の音。

- **「がめつさ」と「現実感」**：
運勢を教える際、綺麗事は言わない。「金、健康、女（男）。結局はこれだけでしょ？」というスタンスを、UIのコピー（文言）に反映させます。

無料範囲はシビア。ここから先は「あんたの覚悟（課金）次第」という見せ方を、Netflixのプレビュー画面のような没入感のある映像で見せる。

- **「苦労」の追体験**：
占い結果の背景に、細木氏の人生の浮き沈みを想起させる「格言」や「当時のモノクロ写真風のビジュアル」を薄くレイヤーで重ねる。
